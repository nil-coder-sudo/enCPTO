enCPTO is a desktop tool that locks files and folders behind a dual cipher cascade — AES-256 + XChaCha20-Poly1305 — keyed by Argon2id and sealed with HMAC-SHA512. Just one password: no PIN, no authenticator app, no accounts, no cloud, no telemetry — the key derivation and the ciphertext never leave your machine.

Spec Sheet

What's under the hood

Every subsystem is built to fail safe: verify before writing plaintext, wipe keys the moment they're used, and never trust a partial result.

01

Dual-cipher cascade

Layer 1 is AES-256-CTR (AES-NI via OpenSSL); layer 2 is XChaCha20-Poly1305 (libsodium) with an independent key. Reading your data means breaking both.

02

Argon2id key derivation

Memory-hard KDF (t=4, m=256MB, p=4, 32-byte salt) resists GPU/ASIC cracking; HKDF-SHA512 splits it into separate keys for every layer.

03

Authenticated everything

Each chunk is sealed to the header, its index and a final-chunk flag, and HMAC-SHA512 covers the whole file — verified before a single byte of plaintext is written.

04

Nothing leaks, nothing to set up

The original filename and type are encrypted too. No PIN, no authenticator, no wizard. Files made by enCPTO v7.0 open unchanged.

05

Every core, every chunk

4 MB chunks are encrypted on all CPU cores while the HMAC and disk writes run alongside. Folders are compressed in parallel in memory; no plaintext archive touches disk.

06

DoD 5220.22-M shredder

Optional 3-pass overwrite (zero → 0xFF → random) of source files after encryption, with an explicit confirmation step before anything irreversible happens.

Get Running

Install in under a minute

Download the app for your system below and open it. Prefer the terminal? Every package also ships encpto-cli.

Terminal — encrypt
encpto-cli encrypt "My Folder" -o backup.dat
Terminal — decrypt
encpto-cli decrypt backup.dat -o restored/
Build from source — CMake, Qt 6, OpenSSL 3, libsodium
git clone https://github.com/nil-coder-sudo/enCPTO.git
cd enCPTO
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Read Before Use

Security notes

!

There is no password recovery. If you forget an encryption key, the data is unrecoverable by design. Your password is the only key — keep it in a password manager. This project has not undergone a formal third-party audit — for regulated or high-stakes use, prefer audited cryptographic libraries. Secure shredding cannot guarantee unrecoverability on SSDs or journaling/snapshotting filesystems. Always keep independent backups of anything important.
