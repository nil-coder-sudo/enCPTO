Spec Sheet

What's under the hood

Every subsystem is built to fail safe: verify before writing plaintext, wipe keys the moment they're used, and never trust a partial result.

01

From-scratch AES-256

Custom S-box, key schedule, and round functions, with a hand-written OpenCL kernel for GPU-accelerated CTR mode. Falls back to a validated CPU path automatically.

02

Argon2id key derivation

Memory-hard KDF (t=3, m=64MB, p=4) resists GPU/ASIC cracking far better than PBKDF2. A lighter profile secures the local unlock PIN.

03

Authenticated everything

HMAC-SHA256 covers the header and every ciphertext chunk. The full tag is verified before a single byte of plaintext is written.

04

PIN + TOTP + recovery

A setup wizard walks you through a local PIN, an authenticator-app TOTP secret, and one-time recovery codes — required before every operation.

05

Streaming folder mode

Whole directories are streamed into a ZIP and encrypted in 4 MB chunks — no multi-gigabyte file needs to fit in memory, and no plaintext archive touches disk.

06

DoD 5220.22-M shredder

Optional 3-pass overwrite (zero → 0xFF → random) of source files after encryption, with an explicit confirmation step before anything irreversible happens.

Get Running

Install in under a minute

enCPTO is a single Python application. GPU acceleration is optional and detected automatically at launch.

Terminal — required
pip install PyQt6 pycryptodome argon2-cffi pyotp qrcode[pil] Pillow
Terminal — optional GPU
# accelerates AES-256-CTR via OpenCL
pip install pyopencl numpy
Terminal — run
python enCPTO-v6-2.py

Read Before Use

Security notes

!

There is no password recovery. If you forget an encryption key, the data is unrecoverable by design. This custom AES-256 implementation has not undergone formal third-party audit — for regulated or high-stakes use, prefer audited cryptographic libraries. Secure shredding cannot guarantee unrecoverability on SSDs or journaling/snapshotting filesystems. Always keep independent backups of anything important.
